# 原始脑电巡检：先检查平线

黄色按钮默认只检查平线。一个扫描窗内峰峰值不超过文件头标定量化步长的0.1倍时，列为平线候选。连续/持续性候选合并显示，供人工核对；仅点击黄色按钮不会写入FIF。

50/60Hz工频、幅度离群及相邻窗基线变化不进入候选，不会因这些原因标红或填入坏道。PSD保留，分析阶段的滤波设置仍由原分析流程控制。

数字饱和与持续电位阶跃可分别勾选，默认关闭。勾选后只建议局部坏段，不建议整道舍弃。阶跃须同时超过最小幅度下限（默认100µV）及通道自身相邻采样差的稳健阈值；前后各100ms、避开边界10ms的中位电位差也须超过幅度下限及局部稳健阈值。偶发单点尖峰或缓慢电压起伏不按原跳变规则提示。阈值是工程筛选参数，不是伪迹的临床判定标准。

绿色按钮区分整道和时间段：仅全程每一窗均为平线，才建议加入整道排除草稿；局部平线及勾选的饱和/阶跃只加入坏段标记，波形不裁剪。80%触发比例仅用于合并列表，不能据此排除整道；多个异常区间之间的正常间隙保留。工频仍跳过。已有人工内容保留；历史FIF和旧分析结果不回写。

当前坏段是全通道的时间注释，保存为MNE的BAD_注释，整道排除另存info['bads']。所有FIF样本和时间位置保留。保存后在单份、多份及镇痛前后入口选择FIF，分析排除整道坏道、跳过与BAD重叠的2秒片段；滤波不跨BAD边界。不应改回读取原BDF来期待它携带FIF标记。

勾选项目、窗长、阈值或范围变更后，旧候选红标立即撤下并要求重新扫描；后端版本与缓存签名一起更新，不沿用旧规则候选。

本次仅调整原始巡检及绿色按钮，不改变历史AUC使用的批量特征质控。当前页面需刷新后重新点击黄色按钮。历史已经保存的坏道标记须由人工决定是否撤销。
